# 📐 Vertex Architecture Portfolio

[![Tech Badge](https://img.shields.io/badge/Stack-HTML5%20%7C%20Sass%20%7C%20BarbaJS-black)](#)
[![Design](https://img.shields.io/badge/Design-Pixel%20Perfect-interstellar)](#)

Un site vitrine ultra-visuel conçu pour un cabinet d'architecture, mettant l'accent sur des transitions fluides, un minimalisme élégant et la mise en valeur des projets.

## ✨ Fonctionnalités Clés
* **Transitions de Pages Fluides :** Changement de page instantané sans rechargement du navigateur (effet application native).
* **Grille Portfolio Asymétrique :** Mise en page moderne et "Pixel-Perfect" pour casser la monotonie des grilles classiques.
* **Dark / Light Mode :** Bascule de thème native pour s'adapter à l'ambiance recherchée par l'utilisateur.
* **Effets Parallaxe :** Animations discrètes sur les images lors du défilement pour un effet premium.
